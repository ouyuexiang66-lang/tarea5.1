# Documentación de Componentes

## Button
Componente base para interacciones.
- **Props**: `label` (texto), `variant` (color), `onClick` (función).
- **Estilos**: Tailwind CSS con transiciones suaves.

## PizzaCard
Tarjeta para mostrar productos del menú.
- **Props**: `pizza` (objeto con id, nombre, precio e ingredientes).
- **Uso**: Se utiliza dentro de un Grid en la página de Menú para mostrar la carta.
